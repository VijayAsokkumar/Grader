# Grader

**Universal test report dashboard with local AI insights — a runnable Python backend MVP.**

**Author:** Vijay Asokkumar  
**Project concept:** June 2026  
**License:** MIT

Grader parses Playwright, Allure, JUnit XML, k6 and Jest reports, scores them using the weighted **NILAI** dimensions, clusters common errors, and produces a conservative **SHIP / REVIEW / BLOCK** recommendation. AI insights are optional and generated by a locally running Ollama model. Without Ollama, a deterministic offline summary is used.

## Quickstart

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
python -m grader --report tests/fixtures/sample-junit.xml
python -m grader --report tests/fixtures/test-results.json --output json
python -m grader --report tests/fixtures/allure-results --ai --model llama3
python -m grader --report tests/fixtures/sample-junit.xml --ci --threshold 80
pytest -q
```

Start the API:

```bash
uvicorn grader.api:app --host 127.0.0.1 --port 8000
# POST a single report file to /api/v1/analyze; /health checks service status.
```

Local Node wrapper (Node 18+, Python 3.11+):

```bash
node bin/grader.js --report tests/fixtures/sample-junit.xml
```

This is **not yet published to npm**. `npx grader` is a future release goal; the local Node bridge runs the Python backend and does not install Python or its dependencies. This repository is a working local-first MVP, not a production-ready service.

## Formats

| Format | Input |
|---|---|
| Playwright | `test-results.json` from JSON reporter |
| Allure | `allure-results/*-result.json` |
| JUnit | `*.xml` JUnit suite files |
| k6 | `summary.json` containing checks |
| Jest | `jest-results.json` |

Input type is detected automatically. For mixed directories, specify `--format`.

## NILAI weighted scoring

| Dimension | Weight | MVP behavior |
|---|---:|---|
| Pass rate | 25% | Executed test pass fraction |
| Flaky index | 15% | Reported flaky fraction |
| Coverage delta | 20% | Needs `--previous-coverage` and `--current-coverage` |
| Duration trend | 15% | Needs `--baseline-duration-ms` |
| Suite breadth | 15% | Needs `--expected-suites` |
| Retry rate | 10% | Fraction of tests with at least one retry |

**Important:** Report formats typically do not include measured source-code coverage or historical execution baselines. Missing dimensions are marked **unavailable** and the weights of the available dimensions are renormalized. The CLI does not fabricate missing data. Thresholds and signal rules are initial release policies, not validated deployment-safety guarantees.

Example with explicit baselines:

```bash
python -m grader --report tests/fixtures/test-results.json \
  --previous-coverage 80 --current-coverage 79 \
  --baseline-duration-ms 100 --expected-suites 1
```

## Local AI / privacy

```bash
ollama serve
ollama pull llama3
python -m grader --report tests/fixtures/test-results.json --ai --model llama3
```

Ollama connections are restricted to `localhost` or loopback. Test names and error messages **are** passed to the local model; a best-effort secret redactor is applied first. Redaction is not a guarantee for arbitrary sensitive data. Do not process regulated/secret reports without extra safeguards. No code or credentials are intentionally sent to an external service.

## Engineer and Product Owner outputs

- **Engineer:** `--output json` includes dimensions, counts, examples and error clusters.
- **Product Owner:** console summary has the score, release signal, and top problems. `--output slack` produces Slack Block Kit JSON for copying into a message; it does not post to Slack.
- **History:** `--record --db .grader/grader.sqlite3` stores basic score-only history; `--history` lists recent runs. This mode is not idempotent.

## Advanced coding-agent assignment

A deliberately **unfinished, explicitly labelled** high-difficulty task lives in [challenge/AGENT_TASK.md](challenge/AGENT_TASK.md): concurrent, idempotent test ingestion with process-safe transactions, crash recovery, test-identity reconciliation and true longitudinal flaky trends.

The current `/api/v1/ingest/atomic` endpoint responds **501** and the `--atomic-history` CLI path raises an explicit not-implemented error. All other supported analysis paths are meant to work.
